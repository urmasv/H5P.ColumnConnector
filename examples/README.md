# Näidised / Examples

## Näidis 1: Prantsuse kunningad (content-A.json)

**Paigutus:** horisontaalsed read (rows)
**Joonte stiil:** sirged jooned (straight)

Ühenda kunningad nende järglastega läbi nelja generatsiooni. Näidis demonstreerib:
- Horisontaalset paigutust
- Erinevate ridade pikkusi
- Sirgjoonelisi ühendusi

## Example 2: Matemaatilised valemid (content-B.json)

**Layout:** vertikaalsed tulbad (columns)
**Line style:** kõverad jooned (curved)

Ühenda matemaatilised mõisted nende valemite ja selgitustega. Näidis demonstreerib:
- Vertikaalset paigutust
- MathJax/LaTeX valemi kasutamist
- Kõverjooni ühendusi
- Mitme ühenduse kasutamist ühe lahtri kohta

## Kasutamine / Usage

Need JSON-failid on H5P sisutüübi seadistusfailid. Neid saab kasutada:

1. **H5P hosts'is** (Moodle, WordPress jne) — importimisvõimalus
2. **h5p-cli arenduskeskkonnas**
3. **Näidisena** koopimisel ja kohandamisel
